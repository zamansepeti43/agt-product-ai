# AGT Product AI — Windows shell

This directory reserves the Tauri 2 desktop shell for the same AGT Product AI web application.

The desktop build intentionally keeps AI inference in the configured server/ComfyUI pipeline. It does not bundle model weights, private endpoints or third-party workflow files.

Planned Windows packaging:

- native window around the Next.js production app
- local development URL during development
- configurable production URL for a hosted deployment
- Windows installer (`.msi` / `.exe`) generated by Tauri CI
- shared workflow with the web/PWA client

Do not put API keys or ComfyUI credentials in this directory.
